# PenguinTools 3.1.5

- Shorten the wait after editing large charts in Margrete Sync by constructing only the speed-area data that C2S export needs.
- Reduce the time spent scheduling AIR and SLIDE notes and comparing speed curves across timelines.

## Requirements

- The managed Windows package requires the .NET 11 runtime. The NativeAOT package is self-contained.
- Both Windows x64 packages require an x86-64-v2 capable CPU.
