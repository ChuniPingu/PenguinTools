# PenguinTools 3.1.3

- Export stereo 48 kHz HCA at 192 kbps to match the game's audio assets.
- Write the generated AWB header and MD5 checksum into each ACB for streaming playback.
- Rebuild cached audio from earlier releases with the updated export format.

Re-export audio for existing option bundles to apply the fix.

## Requirements

- The managed Windows package requires the .NET 11 runtime. The NativeAOT package is self-contained.
- Both Windows x64 packages require an x86-64-v2 capable CPU.
