# PenguinTools 3.1.4

- Speed up live synchronization after note edits, especially on large charts.
- Reduce chart parsing, C2S export, and judgement-count calculation time while preserving note pairing and speed changes.
- Verify large media files in bigger reads so cached media can be reused more efficiently. Media changes still invalidate the cache.

## Requirements

- The managed Windows package requires the .NET 11 runtime. The NativeAOT package is self-contained.
- Both Windows x64 packages require an x86-64-v2 capable CPU.
