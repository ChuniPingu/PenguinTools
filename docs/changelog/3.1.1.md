# PenguinTools 3.1.1

## What's new

- Reuse converted audio, jackets, backgrounds, and field walls across editor saves and worker restarts with an optional persistent media cache
- Add `cacheDirectory` and `cacheIdentity` to session requests and advertise support through the `persistentMediaCache` capability
- Validate source content, conversion settings, cached outputs, and converter identity before reuse; keep published snapshots independent of cache eviction

## Reliability

- Rebuild missing or corrupt cached resources and reject unsafe cache paths
- Preserve the preceding cache when a build fails; keep completed exports usable if cache storage is unavailable
- Invalidate both disk and live-session reuse when the converter identity changes

## Requirements

- The managed Windows package requires the .NET 11 runtime; the NativeAOT package is self-contained
- Both Windows x64 packages require an x86-64-v2 capable CPU

See the [session protocol](https://github.com/ChuniPingu/PenguinTools/blob/v3.1.1/docs/cli.md#incremental-build-session) for cache ownership and caller locking requirements.
