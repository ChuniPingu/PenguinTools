# PenguinTools 3.0.0

## Changes

- Replace `music build` with `option build` for song exports. Place the chart and media in an input folder; that folder can contain a single song

  ```powershell
  PenguinTools.CLI.exe option build .\charts .\out --option-name A001
  ```

## What's new

- Configure field walls with `#meta wall "images/wall.png" wide`. Export them with `option build`, `wall build`, or `wall build-files`; in-game display requires the separate [wallbind plugin](https://github.com/ChuniPingu/wallbind#install)
- Collect field wall IDs with `assets collect` and report wall settings in chart inspection and option scans

## Fixes

- Preserve multiline UGC comments and relative image paths when moving converted charts
- Retain ExTAP effects on shared long-note heads and scroll events after the last note or on unused timelines
- Warn and continue when optional metadata is invalid; truncate oversized MGXC text at a complete UTF-8 character boundary
- Stop audio export if normalization fails, preventing an incorrectly processed audio file from being reported as successful
