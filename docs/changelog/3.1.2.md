# PenguinTools 3.1.2

## What's new

- Encode exported HCA audio at 384 kbps and rebuild cached audio when the encoding bitrate changes
- Reduce repeated file reads and hashing during incremental builds and cached-resource copying

## Reliability

- Retry once when source media or settings change during export; keep the preceding successful revision if inputs remain unstable
- Handle equivalent absolute media paths and verify copied cache files before replacing existing outputs
- Keep published snapshots independent of cached resources

## Requirements

- The managed Windows package requires the .NET 11 runtime; the NativeAOT package is self-contained
- Both Windows x64 packages require an x86-64-v2 capable CPU

See the [session protocol](https://github.com/ChuniPingu/PenguinTools/blob/v3.1.2/docs/cli.md#incremental-build-session) for cache ownership and caller locking requirements.
