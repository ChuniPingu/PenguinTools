# PenguinTools 3.1.0

## What's new

- Add `session`, a persistent UTF-8 JSONL interface for repeated option exports from in-memory UGC or saved MGXC, UGC and SUS files
- Reuse unchanged audio, jackets, backgrounds and field walls across builds, with a per-resource SHA-256 manifest for clients that reload individual assets
- Reuse identical valid UGC snapshots while checking media contents and export settings; expose the same session through `PenguinToolsApplication.CreateBuildSession()`

## Reliability

- Publish independent output snapshots and retain the preceding successful cache when a replacement fails
- Preserve Unicode chart text and paths in the session protocol
- Keep session working paths compact for Windows native media tools

See the [session protocol](https://github.com/ChuniPingu/PenguinTools/blob/v3.1.0/docs/cli.md#incremental-build-session) for requests, responses and cache ownership.
