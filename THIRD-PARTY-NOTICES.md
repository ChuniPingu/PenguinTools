## [DirectXTex / texconv](https://github.com/microsoft/DirectXTex)

The Windows x64 texconv executable is pinned to the `may2026` GitHub release and verified against
`PenguinTools.Assets/native-tools.json`. MIT License. See `PenguinTools.Assets/Licenses/DirectXTex.txt`.

## [image-tools, libvips, and native dependencies](https://github.com/ChuniPingu/image-tools)

Raster processing uses the separately released image-tools executable and its replaceable `libvips-42.dll`. The release is pinned and hash-verified by `PenguinTools.Assets/native-tools.json`. Its license notices, dependency versions, and build metadata accompany the binaries under `assets/image-tools`. The image-tools source and build instructions link to the matching official [libvips Windows build](https://github.com/libvips/build-win64-mxe).
